Read the README and docs/methodology.md before changing calculations.

  connections, personal paths, external personal projects or unlicensed book copies.

- All new original source and documentation is attributed to QRT Solutions under MIT.
  Preserve third-party attribution and distinct data permissions.
- Use relative Markdown links. Never log secrets or raw exception messages. For
  unexpected errors report the exception class and omit internal details.
- This edition excludes the historical notebooks and data from masterclass. Keep the
  full Pine/MQL5 catalog; never reintroduce deferred tracks through generated artifacts.
- Pine source remains version 6. Preserve closed-bar semantics in MQL5/Pine.
- Native compiler availability and numeric parity are separate from registry checks.
- Update CHANGELOG.md for meaningful changes. Do not publish or replace remote history
  before the release evidence is complete and the final candidate is approved.
