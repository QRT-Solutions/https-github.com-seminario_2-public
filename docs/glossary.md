# Glosario y errores frecuentes

| Término | Significado |
|---|---|
| ATR | Promedio de rango verdadero; documentar ventana y desplazamiento |
| MAE / MFE | Excursión adversa / favorable durante el intervalo observado |
| R | PnL dividido por riesgo inicial al stop; especificar bruto o neto |
| IS / OOS | Segmentos de selección / evaluación |
| Contrato | Especificación explícita de reglas y artefactos |
| Reproducibilidad | Reconstruir una comprobación con recursos identificados |
| Paridad | Equivalencia numérica entre implementaciones |

**No encuentra proyecto:** entra al clon o indica `--project`.
**Falta un módulo:** ejecuta `uv sync --locked --group dev`.
**Copia desincronizada:** edita la fuente canónica y regenera con el deployer.
**Contrato válido, compilación fallida:** son comprobaciones distintas; conserva el log local.
**Faltan notebooks o históricos:** están fuera del alcance de esta edición, no son una instalación incompleta.
**Resultado de backtest diferente:** compara fuentes, datos, parámetros, costes, sesiones y versión del compilador antes del gráfico.
