# Importación autorizada de la base de conocimientos

Autor: QRT Solutions.

Se publica la carpeta pedida por el mantenedor. La autorización expresa de publicación
y uso compartido amplía el alcance de la edición pública anterior.

Se conservan byte a byte los 50 documentos para evitar alterar fórmulas y ejemplos.
Los dos índices se corrigen para navegación y para declarar la ausencia de imágenes.
Un manifiesto relaciona hashes de origen y publicación; las atribuciones se conservan.

El verificador de enlaces informa referencias históricas ausentes solo para documentos
importados cuyo hash siga coincidiendo con el original registrado. Índices, archivos
nuevos o modificados no reciben esa excepción. El escaneo de secretos sigue abarcando
toda la carpeta y el historial. Se verificará la excepción, su invalidación al editar,
la documentación, el catálogo de estrategias y CI en tres plataformas.

La copia íntegra sin registrar sus enlaces ausentes rompería CI; reescribir los textos
para eliminar esas referencias podría alterar fórmulas y ejemplos. La importación
con hashes preserva el material solicitado y hace explícita su cobertura de validación.

El escáner comprueba que un valor Basic decodifique un par usuario:contraseña;
las palabras inglesas corrientes no son credenciales. Una URL bibliográfica pública
exacta se distingue de las rutas de usuario locales. Las pruebas conservan la
detección de credenciales reales sintéticas y de rutas personales adyacentes.
